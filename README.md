## 🇺🇸 English

### 🎯 Overview
**HQ Tracker** is an ultra-fast, mobile-first web application designed for comic book readers and collectors to track monthly publications and miniseries in a single streamlined screen. It features an intuitive chunking mechanism that displays issues in groups of 10 with interactive badges, auto-collapsing completed intervals (e.g. `01..10`) and dynamically revealing subsequent issue blocks.

### ✨ Key Features
- **Single-Screen Experience:** Optimized for one-thumb mobile interaction.
- **Smart Chunking:** Issues displayed in clusters of 10. Completed ranges summarize into concise badges (`01..10`), expanding seamlessly to the next bracket (`11..20`).
- **Series Completion:** One-click termination to mark limited runs or completed miniseries (e.g., `01..06`).
- **Fast Management:** Quick inline naming, editing, and confirmation-protected deletion.
- **Persistent & Real-time:** Built on Firebase Firestore with offline-first local cache synchronization.

## 🇧🇷 Versão em Português (Brasil)

### 🎯 Visão Geral
O **HQ Tracker** é uma aplicação web mobile-first ultra-rápida criada sob medida para colecionadores de quadrinhos organizarem edições mensais e minisséries em apenas uma tela. O sistema emprega uma lógica inteligente de blocos de 10 edições com bolinhas táteis, resumindo automaticamente sequências completas (ex: `01..10`) e abrindo novas dezenas dinamicamente conforme a coleção avança.

### ✨ Principais Funcionalidades
- **Experiência em Tela Única:** Interface projetada para uso com uma só mão em smartphones.
- **Agrupamento Inteligente (Chunking):** Números divididos em grupos de 10. Intervalos completos viram badges compactos (`01..10`), abrindo o próximo intervalo (`11..20`).
- **Encerramento de Títulos:** Botão de finalização rápida para minisséries ou títulos cancelados (ex: `01..06`).
- **Edição & Remoção:** Edição ágil do título e exclusão com modal de confirmação de segurança.
- **Persistência em Nuvem:** Integrado ao Firebase Firestore com suporte a cache offline.

### 🤖 Desenvolvido com Google Antigravity
Projeto concebido e executado através do ecossistema **Google Antigravity**, operando na Arquitetura de 3 Camadas:
- **Camada 1 (Diretivas):** SOPs estratégicos em `/directives/`.
- **Camada 2 (Orquestração):** Inteligência central via Agente Orquestrador (`agente-orquestrador`).
- **Camada 3 (Execução):** Scripts utilitários determinísticos em `/execution/`.

**Agentes de IA e Skill Packs Utilizados:**
- `agente-orquestrador` (Orquestração determinística e auto-recuperação)
